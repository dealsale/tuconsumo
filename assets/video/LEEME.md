# Videos de Willy

Coloca aquí los archivos .mp4 de Willy (si no usas YouTube/Vimeo) y enlázalos en
`assets/js/config.js` → `videos`. Ejemplo:

```js
bienvenida: { src: "assets/video/bienvenida.mp4", vertical: false, title: "Willy te da la bienvenida", duration: "1:00" }
```

Recomendado: MP4 H.264, 1080p, menos de 30 MB. Para videos largos es mejor YouTube (no listado).
